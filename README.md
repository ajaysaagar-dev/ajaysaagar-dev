## 👨‍💻 About Me

I am a multidisciplinary **Software Engineer & Systems Architect** with over **7+ years** of hands-on experience spanning game engine development, multi-agent AI ecosystems, reactive UI frameworks, and enterprise full-stack distributed systems.

- 🎮 **Game & Graphics Engineering**: Architecting modular plugin-based 3D/2D game engines with Babylon.js, WebGL shaders, and Unreal Engine 5.
- 🤖 **Autonomous AI & Multi-Agent Systems**: Designing robust multi-agent orchestration, evaluation harnesses, and long-term memory graph architectures.
- ⚡ **Framework & Developer Tooling**: Author of [**Orino.js**](https://github.com/ajaysaagar-dev/OrinoJS) (reactive UI framework) and [**OctoPulse**](https://github.com/ajaysaagar-dev/octo-pulse) (repository telemetry CLI).
- 🌐 **Enterprise Cloud Architecture**: Building resilient microservices and full-stack platforms with Next.js 15, React 19, TypeScript, PostgreSQL, Prisma, Docker, and NGINX.
- 🔒 **Security & Identity**: Implementing Identity & Access Management (IAM), RBAC, OAuth/JWT pipelines, and automated SAST/DAST vulnerability assessments.
