## About Me

Hi, I'm **Ajaysaagar**, a developer passionate about building game engines, AI-powered systems, and modern web applications.

- Game Engine Development with Eunoia Engine and Unreal Engine 5.
- Full-Stack Development with React, Next.js, Node.js, and TypeScript.
- AI Development with multi-agent systems and LLM orchestration.
- 3D Graphics, Rendering, and Software Architecture.
- Developer Tools, Cloud Systems, and Application Development.

I enjoy turning creative ideas into practical, high-performance software.
